
# PioAgent Documentation

Welcome to the **PioAgent** customer documentation. PioAgent is an agent
platform that lets your team manage users and tasks through a simple,
predictable REST API.

## What you can do

- **Users API** — list and look up user accounts in your workspace.
- **Tasks API** — list tasks created by your agents.

## How this documentation works

The API reference in this portal is generated from the PioAgent service's
OpenAPI specification. When the service team changes the API, the
documentation is updated automatically through a review workflow — so what
you read here always matches the deployed API.
