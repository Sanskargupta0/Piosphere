# Changelog

## 1.0.0 — Initial API release

Initial public release of the PioAgent customer API.

### Added

- **Users API**
  - `GET /api/v1/users` — list all users in the workspace.
  - `GET /api/v1/users/{id}` — retrieve a single user by ID.
- **Tasks API**
  - `GET /api/v1/tasks` — list all tasks, with optional `status` filter.
- API key authentication via the `Authorization: Bearer` header.
